Tripwire

Catches stolen AWS keys from CloudTrail and sends one Slack alert per incident, not one per event.

Every identity gets its own Isolation Forest over 7 rarity features: API, source IP, region, user agent, hour, burst rate and error rate. Flagged calls are grouped by identity and IP and tagged with MITRE ATT&CK techniques. Bedrock writes the summary and names the key to rotate.

  • 1alert per attack, 5 of 5 test weeks
  • 0.33%false positives on unseen traffic
  • 0.12 msto score one call

Python · Lambda · EventBridge · DynamoDB · Bedrock · Terraform

02building

HawkPlan

Turns the ULM catalog into a semester by semester plan, and answers advising questions with citations.

The catalog is parsed into a prerequisite graph in Postgres. The planner is a topological sort with list scheduling: each term takes the available courses on the longest remaining chain first, under a credit cap and fall or spring only offerings. Questions go through a RAG pipeline over pgvector, and every answer cites its catalog section.

  • 50real advising questions in the eval set
  • 3CS tracks planned end to end

Next.js · TypeScript · PostgreSQL · pgvector · Python · RAG

Run the demo
03building

Relay

An LLM gateway that stops you paying twice for the same question and stays up when a provider goes down.

Prompts above 0.95 cosine similarity get the stored answer from a Redis semantic cache, with hit rate and dollars saved tracked per day. Every API key gets a token bucket. When the main provider starts returning 503s, a circuit breaker fails traffic over to the second one, checked with k6 load tests.

  • 0.95cosine threshold for a cache hit
  • 0client errors in the failover sim

TypeScript · Node.js · Redis · PostgreSQL · Docker · k6

Run the demo
04building

Satya

Satya means truth in Nepali. A fake news classifier that labels posts as you scroll, cheap enough to run on a CPU.

DistilBERT and RoBERTa are fine tuned on the same LIAR and FakeNewsNet splits and picked on per class precision, recall and macro F1. LIAR is imbalanced and accuracy hides it. The winner is exported to ONNX with INT8 quantization and served from FastAPI on ECS. A Chrome extension sends every visible post in one request per scroll.

  • ~4xsmaller weights after INT8
  • 1request per scroll, not per post

PyTorch · Hugging Face · ONNX · FastAPI · Docker · AWS ECS
